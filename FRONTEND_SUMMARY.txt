1. TECHNOLOGY STACK AT A GLANCE
================================================================================

CORE FRAMEWORK:
  • React 18.2.0 (UI library)
  • React Router 6.30.1 (client-side routing)
  • Create React App with Craco (build tool)

STATE MANAGEMENT:
  • React Query 3.39.3 (server state + caching)
  • React Context API (auth + theme global state)
  • localStorage (persistent storage)

STYLING:
  • CSS with dynamic variables (primary approach)
  • Tailwind CSS 3.3.3 (utility framework - installed)
  • Supports 3 themes: light, dark, crypto

UI/UX:
  • Lucide React 0.263.1 (modern icons)
  • Heroicons React 2.0.18 (alternative icons)
  • React Hot Toast 2.4.1 (notifications)
  • Recharts 3.2.1 (charts and graphs)

API & AUTHENTICATION:
  • Axios 1.10.0 (HTTP client with interceptors)
  • JWT tokens (stored in localStorage)
  • Google OAuth integration
  • 2FA (Two-Factor Authentication)

FORMS:
  • React Hook Form 7.45.2
  • Custom validators + date-fns

3. STATE MANAGEMENT BREAKDOWN
================================================================================

GLOBAL STATE (Available everywhere):
  • useAuth() - Current user, login/logout, isAuthenticated
  • useTheme() - Theme mode, theme config, toggleTheme()

SERVER STATE (React Query):
  • useQuery() for fetching data
  • useMutation() for creating/updating data
  • Automatic caching with 30-second stale time
  • Retry on failure (1 attempt)

LOCAL STATE (Component-specific):
  • Form inputs via useState
  • Dropdown/modal toggles
  • Loading spinners
  • Temporary calculations

API INTERCEPTORS:
  • Request: Auto-inject JWT token from localStorage
  • Response: Smart 401 handling with public route whitelist

7. API INTEGRATION DESIGN
================================================================================

API CLIENT (src/api/client.js):
  • Axios instance with interceptors
  • Automatic JWT injection in headers
  • 401 error handling with smart redirect
  • Public routes whitelist (prevents redirect loops)

ENDPOINTS (src/api/endpoints.js):
  • Centralized endpoint definitions
  • Dynamic endpoints with parameters
  • Organized by feature

EXAMPLE ENDPOINT USAGE:
  const response = await apiClient.get(ENDPOINTS.MY_BALANCES);
  const price = await apiClient.get(ENDPOINTS.EXCHANGE_PRICE('BTC', 'USDT'));

12. PERFORMANCE OPTIMIZATIONS
================================================================================

  • Stale time: 30 seconds (data freshness period)
  • No refetch on window focus
  • Retry: 1 attempt on failure
  • Automatic cache invalidation

COMPONENT LEVEL:
  • Proper hook dependencies
  • Debounce: 500ms for price calculations
  • Lazy loading of market data pages
  • Conditional rendering

RENDERING:
  • Skeleton loaders vs spinners
  • Loading states prevent duplicate requests
  • Modals for confirmations (no page reload)
